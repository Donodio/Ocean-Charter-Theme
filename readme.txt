== Description ==

Ocean Charter is a premium WordPress theme built specifically for boat charter and yacht rental businesses. It features:

* Complete booking management system
* Fleet showcase with detailed boat specifications
* Destination management
* CRM integration capabilities
* Elementor page builder support
* One Click Demo Import

== Installation ==

1. Upload the `ocean-charter` folder to the `/wp-content/themes/` directory
2. Activate the theme through the 'Appearance > Themes' menu in WordPress
3. Install recommended plugins when prompted

== Frequently Asked Questions ==

= Is this theme compatible with Elementor? =

Yes, Ocean Charter includes full Elementor page builder support.

= Does this theme support online bookings? =

Yes, the theme includes a complete booking management system.
